# GATEHOLD

Оборона ворот от огромной орды: тысячи врагов, турели, ракетница, умения и удары с неба.
Low-poly, движок Godot 4.

*A first-person horde defense game: thousands of enemies, turrets, a rocket launcher, abilities and air strikes. Built with Godot 4.*

## Как поиграть / How to play

1. Скачай **Godot 4.7.2** (обычная версия, не .NET): https://godotengine.org/download
   *Download **Godot 4.7.2** (standard, not .NET).*
2. Скачай этот проект: зелёная кнопка **Code → Download ZIP**, распакуй.
   *Download this project: green **Code → Download ZIP**, unzip it.*
3. Запусти Godot → **Import** → выбери файл `project.godot` из распакованной папки → **Import & Edit**.
   *Open Godot → **Import** → pick `project.godot` → **Import & Edit**.*
4. Первый импорт займёт минуту. Потом нажми **▶ (F5)** вверху справа — игра запустится.
   *The first import takes a minute. Then press **▶ (F5)** in the top right to play.*

Язык меняется в игре: **Настройки → Язык / Language**.
*Language: **Settings → Язык / Language**.*

## Управление / Controls

| | |
|---|---|
| ЛКМ / LMB | выстрел / fire |
| Q E R | умения / abilities |
| Z X C | удары с неба / air strikes |
| B | стройка турелей / build turrets |
| U | прокачка / upgrades |
| Enter | выпустить орду / release the horde |
| Пробел, WASD / Space, WASD | полёт на ранце / jetpack flight |
| Esc | пауза / pause |
