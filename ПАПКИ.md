# GATEHOLD — что где лежит

| Папка | Что внутри |
|---|---|
| `core/` | Ядро игры: запуск и ход боя (`main.gd`, `waves.gd`), сохранение (`progress.gd`), настройки, древо прокачки — данные (`upgrades.gd`), награды за локации (`mastery.gd`) |
| `hero/` | Герой: полёт на ранце и здоровье (`player.gd`), умения Q/E/R (`hero_abilities.gd`), боевой дрон (`drone.gd`), руки; `models/` — перчатки |
| `i18n/` | Перевод: `en.gd` — английский словарь (ключ — русский текст из кода). Язык переключается в настройках; переводчик — `core/lang.gd`. Новая надпись в игре → добавить строку сюда |
| `weapons/` | Ручное оружие: ракетница (`blunderbuss.gd`, модель — `launcher_model.gd`), ракета (`shell.gd`), миниган, огнемёт, гравипушка, дискомёт (`saw_gun.gd`), электропушка (`lightning_gun.gd`), молот (`hammer.gd`) — у каждого своя модель `*_model.gd`; `model_kit.gd` — простые формы для моделей; `models/` — старые 3D-модели. Цены оружия и ветки его прокачки — `core/upgrades.gd` (WEAPONS, узлы w_*) |
| `turrets/` | Турели: пулемёт, заморозка, огнемёт, лазер (`turret.gd`), стройка и постаменты (`turrets.gd`), модели (`turret_models.gd`); `models/` — старые модели |
| `mobs/` | Враги: орда (`horde.gd`), модели гоблинов и жуков (`mobs.gd`), копья по герою (`spears.gd`), звуки орды; `shaders/` — анимация шагов; `bosses/` — модели боссов (пока выключены) |
| `locations/` | Локации: список и настройки всех 10 (`levels.gd`), постройка карты — каналы, скалы, туннель, деревья (`map_builder.gd`), замок для старых локаций (`base_builder.gd`) |
| `effects/` | Взрывы, огонь на земле, чёрная дыра, огненный торнадо, шаровая молния, удар молнии с неба, цепная молния, ударная волна молота; `shaders/` — их шейдеры |
| `ui/` | Интерфейс: в бою (`hud.gd`), меню (`menu.gd`), экран прокачки и магазин оружия (`upgrade_tree.gd`), экран поражения (`game_over.gd`), обучение; `icons/` — иконки умений и картинки оружия для магазина; `tree_bg.jpg` — фон прокачки |
| `audio/music/` | Музыка: меню (`music_menu.mp3`), стройка обороны (`music_build.mp3`), бой (`music_fight.mp3`), победа и поражение; проигрыватель (`music.gd`) |
| `audio/sounds/` | Звуки: выстрелы, взрывы, орда, турели |
| `scenes/` | Главная сцена игры (`main.tscn`) |
| `art_src/` | Исходники моделей для Blender и картинки-референсы (в игру не попадают) |
| `tools/` | Служебное: боты-игроки для баланса, замер FPS, снимки экрана, генераторы звуков и музыки; `trailer/` — сборка трейлера |
| `build/` | Готовое для передачи: проект целиком (`GATEHOLD.zip`) и трейлер (`GATEHOLD_trailer.mp4`). Godot эту папку не сканирует (`.gdignore`) |
